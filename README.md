# Kombi Bar Diplomasi Protokolü

> Resmi sınıflandırma: Ciddi. Alt sınıflandırma: Değil.

Bu depo, Türkiye Cumhuriyeti sınırları içindeki tüm kombilerin dışişleri bakanlığıdır. Bar değeri bir sayı değil, bir niyettir. 1.2 bar barış, 0.6 bar nota, 0.0 bar büyükelçi çağrılmasıdır.

## Neden var

Çünkü pazartesi sabahı 09:05'te birinin aklı takıldı ve takılan akıl boşa gitmesin diye enstitü kuruldu. Anlam şart değildi. Çalışmak şarttı.

## Kurulum

Python 3 yeter. Bağımlılık yok. Kombinin kendisi bağımlılıktır, onu buraya koymayın, ısınır.

```bash
python3 protokol.py
python3 protokol.py --bar 0.7 --dis-hava 3 --petek 4 --mod nota
```

## Ne yapar

1. Bar değerini diplomatik statüye çevirir.
2. Dış hava ile iç haysiyet arasında müzakere yapar.
3. Petek başına düşen ısıyı abartılı biçimde hesaplar.
4. Tutanak basar. İtiraz mercii yoktur. İtiraz ederseniz petek sesi çıkarır.

## Protokol cetveli

| Bar | Statü | Muhtemel sonuç |
| --- | --- | --- |
| 0.0 - 0.5 | Büyükelçi çağrıldı | Salon paltoyla ısınır |
| 0.5 - 1.0 | Nota verildi | Çorap iki kat |
| 1.0 - 1.5 | Toplu sözleşme | Medeni ısı |
| 1.5 - 2.0 | Fazla iyimser | Vana terler |
| 2.0+ | Emniyet sibobu konuşur | Halı diplomatik kriz |

## Katkı

Fork'lamak serbesttir. Yıldız vermek protokole aykırı değildir ama kombi yıldızı anlamaz, bar anlar.
